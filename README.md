# 🌍 Путешествие по России

## Описание проекта

"Путешествие по России" — это адаптивный веб-сайт, посвященный путешествиям по удивительным местам России. В проекте представлены красивые фотографии природы, описания популярных маршрутов и интересные факты о достопримечательностях страны.

## 🚀 Функциональность
- 📷 Галерея с живописными фото  
- 📍 Список популярных мест для путешествий  
- 📱 Полная адаптивность (мобильные и десктопные версии)  
- 🌎 Переключение языков (RU / EN)  

## Используемые технологии

- HTML5
- CSS3 (Flexbox, Grid)
- Методология БЭМ
- Адаптивная и кроссбраузерная верстка
